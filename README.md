# Protein Tracker PWA

A standalone installable Progressive Web App for tracking daily protein, calories, carbs and fat.

## Files
- index.html — app
- manifest.webmanifest — install metadata
- sw.js — offline cache
- icon.svg — app icon

## Install on Android
1. Put these files on a web host with HTTPS.
2. Open the site in Chrome on your phone.
3. Tap Install / Add to Home screen.

## Easy hosting
GitHub Pages is a simple free option:
1. Create a GitHub repository.
2. Upload all four files.
3. Enable GitHub Pages in the repository settings.
4. Open the generated HTTPS site on your phone.
5. Install it from Chrome.

The app stores your food database, target and daily entries in the browser's local storage on that device.
